# Themes

`Mod+Shift+T` switches the `~/.config/kali-clean/current` symlink between these themes and reloads i3/tmux/Dunst/Alacritty styling.

- **obsidian** — Pebl3-inspired monochrome minimalism.
- **neon** — dark navy base with restrained cyan/violet accents.

Both remain fully opaque and intentionally avoid Picom so VMware/Thunar rendering stays reliable.
